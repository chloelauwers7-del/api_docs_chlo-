Order Management API Error Codes

List of possible error codes and their solutions.

400 - Bad Request

The request contains invalid or missing data.

Solution: Verify all required fields before sending the request.

401 - Unauthorized

Authentication failed.

Solution: Check that the API key is valid and correctly configured.

404 - Not Found

The requested resource does not exist.

Solution: Verify the endpoint URL and resource identifier.

500 - Internal Server Error

An unexpected server error occurred.

Solution: Retry the request later or contact support.
