Order Management API Endpoints

List of available endpoints for order management.

Get All Orders

Method: GET URL: /orders

Returns a list of all orders.

Response (200): 
[{"id": 101, "customer": "John Smith", "status": "Processing"}]

Create Order

Method: POST URL: /orders

Creates a new order.

Request Body Fields:
  • customer (string, required)
  • product (string, required)
  • quantity (integer, required)
Request Example: 
{"customer":"John Smith", "product":"Laptop", "quantity":1}
Response (201): 
{"id":102, "status":"Created"}

Get Order Details

Method: GET URL: /orders/{id}

Returns details for a specific order.

Parameter: id (integer) – Unique order identifier.

Response (200): 
{"id":101, "customer":"John Smith", "product":"Laptop", "quantity":1, "status":"Processing"}
